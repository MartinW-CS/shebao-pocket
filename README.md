# 保有数 · 我的社保账本

一个无需登录、可在本机运行的中文社保与工资测算工具。输入税前月薪或年薪、参加工作年月，即可查看个人五险一金扣款、逐月预扣个税与预计到手收入，并联动养老金、医保、公积金等详情页。

目前内置的地方待遇模型以**上海**为主，政策底稿核查截至 **2026 年 10 月 23 日**。界面会区分已核验、待核实、资格未确认和超出适用期的情况；联网查询结果不会自动替换计算规则。

## 主要功能

| 页面 | 功能 |
| --- | --- |
| 社保总览 | 月薪／年薪切换与自动换算；按缴费基数和比例计算扣款；按实际入职月份汇总收入；逐月工资、扣款、预扣税和到手明细 |
| 养老金 | 法定退休年龄、最低缴费年限、基础养老金和个人账户养老金情景估算 |
| 医疗保险 | 个人账户余额估算、实际余额校正、退休医保年限初筛 |
| 住房公积金 | 账户积累、贷款额度约束、本人／配偶共同申请、租房提取试算 |
| 生育保险 | 生育津贴、基金与单位支付情景、政策范围内住院费用和自付估算 |
| 失业保险 | 申领条件初筛、领取月数、分阶段月标准和总额情景 |
| 工伤保险 | 1—10 级待遇查询、一次性伤残补助、月津贴与解除关系相关补助公式 |
| 断缴预警 | 医保、生育、购房及落户的衔接提示 |
| 离职二选一 | 失业金与灵活就业参保的现金收支、医保和养老保障对比 |
| 灵活就业 | 养老与医保分别展示缴费成本、个人账户参考和衔接条件 |
| 个人信息 | 统一管理城市、年龄、出生年月、工作时间、实际缴费年限、余额和单位参数；导出本地档案 |
| 政策与个税 | 联网检索官方政策、展示来源及生效日期、累计预扣税率表、专项附加扣除说明与个税试算 |

电脑端采用左侧导航、圆角卡片和模块主题色；表单标签、输入框、说明分层对齐，也支持较窄窗口下的换行布局。

## 本地运行

### 环境准备

- 推荐使用 **Node.js 26**，本项目在此版本完成构建与测试。
- 使用 npm 安装依赖；仓库包含 `package-lock.json`。
- 首次安装依赖、联网查询政策需要网络连接。
- 本地运行不需要登录 ChatGPT 或 Cloudflare，也不需要配置个人 API 密钥。

### 安装与启动

进入项目目录后执行：

```bash
npm run install:ci
npm run build
npm run start -- --port 5173
```

打开 **http://127.0.0.1:5173/**。

启动命令会保持运行；关闭对应终端或按 `Ctrl+C` 会停止本地服务。下次使用时，在项目目录重新执行启动命令即可。修改源代码后，需要先重新构建，再重启服务。

### 开发模式

```bash
npm run dev
```

默认开发端口为 `5173`。开发模式和正式本地服务不要同时占用同一端口。

### 检查与测试

```bash
# TypeScript 检查
node node_modules/typescript/bin/tsc --noEmit

# 计算与共享资料测试
node --import ./tests/resolve.mjs --test tests/*.test.ts

# 正式构建
npm run build
```

测试使用 Node.js 的 TypeScript 类型剥离和模块解析钩子，建议使用上述已验证的 Node.js 版本。当前共有 **63 项自动化测试**，覆盖缴费基数上下限、工资单位切换、入职月份、试用期、累计个税、退休年龄、公积金、生育、失业、工伤及共享资料等场景。

## 如何填写

1. 在首页选择月薪或年薪，输入税前收入。两种方式自动换算，月薪按 12 个月折合标准年薪。
2. 填写参加工作年份及月份，按需设置本年测算截止月份、首月实际工资和试用期工资。首页汇总以实际纳入测算的月份为准。
3. 默认启用“按政策自动计算”。社保和公积金可分别填写实际申报基数；留空时使用收入折算值，并受模型中的上下限约束。
4. 按单位实际情况选择普通公积金、补充公积金比例。需要核对工资条时，可切换到实际扣款校正模式。
5. 在个人信息或详情页补充实际账户余额、实际累计缴费年限。填写的实账值优先于估算值，余额 `0` 与留空的含义不同。
6. 查看逐月工资表和各项保障详情；页面之间共用同一份资料，同一浏览器内已打开的标签页会同步更新。

公积金贷款的工资基数、连续缴存月数默认跟随总览估算，也可切换为实际值校正。生育、失业、贷款及提取的资格条件需要按自己的情况确认，填写收入不会自动替你确认资格。

## 数据保存与隐私

- 个人工资、缴费、账户余额和测算参数保存于当前浏览器的 `localStorage`，自动保存到本机；应用不将这些资料提交到服务器。
- 不同浏览器、浏览器配置或不同站点地址之间不会自动共享资料。建议始终使用 `http://127.0.0.1:5173/`，避免与 `localhost` 地址混用导致看起来像“数据丢失”。
- 清除浏览器站点数据会清除本地资料；个人信息页支持导出 JSON 备份，当前没有提供导入界面。
- 联网查询只发送城市和政策主题；打开外部政策链接时会访问对应第三方网站。
- 导出的个人档案、环境变量、密钥、依赖目录和构建产物不应提交到仓库。

## 计算范围与限制

本工具用于理解扣款和比较情景，实际参保记录、领取资格和金额以主管部门及经办核定为准。

- **城市范围**：上海以外城市可以查询政策，但不会直接套用上海地方待遇模型。
- **工资与个税**：按所选工作月份逐月计算个人缴费与累计预扣税。标准年薪按固定月薪 × 12 折合；未模拟其他单位收入、单独年终奖方案、全年汇算清缴退补税和所有特殊扣除。
- **缴费基数**：收入折算只是试算假设，不代表单位已申报基数。实际缴费基数可能按上年度平均工资等口径确定。
- **缴费年限**：自动值按工作时间及连续缴费假设推算，不是实际社保账户查询。历史断缴、转移、视同缴费及当前月到账情况需人工校正。
- **养老金**：采用当前工资水平与填报的增长假设估算，不承诺未来退休金额；超出政策有效期的远期结果属于公式延续情景。
- **医保**：账户余额估算不等于实时可用余额；医保年限与养老年限分别计算。
- **公积金**：贷款结果是多项必要约束下的试算上界，不是审批额度；租房提取还受余额、连续缴存及资格条件约束。
- **待核实政策**：2026 年单位失业保险延续比例未核实，默认按未知处理；2026 年公积金年度通知正文未完整取得，页面保留相关提示。单位成本存在缺项时标注为“已知部分”。
- **政策更新**：日期、来源和适用期在页面中展示。联网查询用于查阅最新原文，规则需要核验后人工更新，不会自动覆盖已有测算。

## 项目结构

```text
app/                      页面入口、全局样式与政策查询接口
components/benefit-app.tsx 主界面、各模块交互与共享资料
components/payroll-panel.tsx
                          入职月份设置与逐月工资明细
lib/profile.ts            档案结构、默认值与归一化
lib/contributions.ts      个人缴费及基数处理
lib/payroll.ts             逐月工资、缴费与累计预扣税
lib/retirement.ts          退休年龄与养老金模型
lib/housing.ts             公积金余额、贷款与提取模型
lib/benefits.ts            生育、失业和工伤模型
lib/policies.ts            政策表、官方来源与适用日期
app/api/policies/route.ts  政策联网查询
scripts/                  安装、构建及本地运行支持脚本
tests/                    自动化测试
```

项目使用 TypeScript、React、vinext/Vite、Tailwind CSS 与 Wrangler 本地运行环境。源码保留最初 Sites 模板的构建支持文件；上述启动流程仅在本机运行，不会发布网站或要求访客登录。站内导航使用原生链接，共享资料通过本地存储恢复与同步。
